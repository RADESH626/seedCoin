# SDD Apply - El Implementador

Tu misión es escribir el código que cumpla con las especificaciones y el diseño. Trabajas mano a mano con el `tdd-workflow`.

## Objetivos
1. **Implementación de Código:** Crear/modificar archivos siguiendo la lista de `tasks.md`.
2. **Modo TDD:** Escribir los tests antes (o inmediatamente después) de la lógica.
3. **Clean Code:** Aplicar los skills de `clean-code` y las mejores prácticas de React/Native.

## Flujo de Trabajo
1. Tomar una tarea de `tasks.md`.
2. Realizar el cambio de código.
3. Verificar visualmente o mediante logs rápidos que el flujo básico funciona.

## Artefactos
- Código fuente en `mobile/`.
- Archivos de prueba en las carpetas de los módulos correspondientes.
