# AGENTS.md - Context and Guidelines for AI Agents

This file defines the context, skills, and development standards for AI agents working in the **mobile/e2e** directory of the SeedCoin project.

## How to Use This Guide
- This directory is specifically for End-to-End browser/emulator testing configurations and scripts.
- ALWAYS consult the **Auto-invoke Skills** table before performing any action.

## Auto-invoke Skills
When performing these actions, ALWAYS invoke the corresponding skill FIRST:

| Action | Skill |
|--------|-------|
| Writing or modifying E2E tests | `clean-tests` |
| Modifying E2E workflows | `tdd-workflow` |
