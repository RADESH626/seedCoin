# AGENTS.md - Context and Guidelines for AI Agents

This file defines the context, skills, and development standards for AI agents working in the **mobile/components** directory of the SeedCoin project. This folder contains reusable UI components.

## How to Use This Guide
- Design components focusing on reuse, single responsibility, and atomic design.
- Define prop interfaces clearly.
- ALWAYS consult the **Auto-invoke Skills** table before performing any action.

## Auto-invoke Skills
When performing these actions, ALWAYS invoke the corresponding skill FIRST:

| Action | Skill |
|--------|-------|
| Creating or modifying UI components | `frontend-development` |
| Working with NativeWind/Styles | `styling` |
| Writing clean, small functions | `clean-functions` |
| Refactoring React 19 hooks or refs | `modern-react` |
| Implementing test cases for components | `clean-tests` |
| Checking TS compilation or Build | `verify-build` |
