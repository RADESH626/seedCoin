# Historial de Tareas 📅

Esta carpeta funciona como un archivo muerto o "log" de auditoría técnica.

El objetivo general es evitar que el archivo de tareas principal (`tareas/todo.txt`) colapse alcanzando longitudes inmanejables cada que se finalice un bloque grande de desarrollo (como refabricar el tablero, implementar un API, etc.).

## ¿Cómo utilizarnos?
- Cuando la IA o tú completan sistemáticamente grandes entregables listados en el MVP o en los TODOs diarios.
- Se "copian y pegan" esos ítems completados hacia este repertorio en archivos fechados (`Ej. tareas-abril-2026.md`) indicando que todo ese grupo ha sido archivado exitosamente.
- Ayuda a conocer a futuro la velocidad de resolución y el hilo conductor que siguió el proyecto en el tiempo.
