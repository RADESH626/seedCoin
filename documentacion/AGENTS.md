# AGENTS.md - Context and Guidelines for AI Agents

This file defines the context, skills, and development standards for AI agents working in the **Documentación** directory of the SeedCoin project.

## How to Use This Guide
- Start here for folder-specific norms when writing documentation.
- The documentation in this folder is intended for human readers and must be written entirely in **Spanish**.
- Use Markdown for text, diagrams formatting, and guidelines.
- ALWAYS consult the **Auto-invoke Skills** table before performing any action.

## Auto-invoke Skills
When performing these actions, ALWAYS invoke the corresponding skill FIRST:

| Action | Skill |
|--------|-------|
| Reviewing or formatting documentation | `clean-comments` |
| Performing a project audit of documentation | `deep-audit` |
| Creating guidelines for AI agents | `workflow` |
